# 用输出倒逼输入

## 什么是输入，输出？

- 笔记、视频、文章
- 对找工作有帮助
- 表达力

## 为什么输出可以促进输入呢？

- 费曼学习法
  - 把自己学到的知识可以输出给其他人
  - 一边加深自己对知识的理解
  - 一边倒逼自己去查其他的资料（输入）
- 不一定非得对人去输出，也可以对一个事物
- 比如程序员的Rubber Duck Debugging 小黄鸭版的程序Debug
  - 锻炼表达能力和写作能力
  - 在现在这个互联网很发达的时代，可以用视频、文本、代码等开源出去，让各路高手来评论，来促使自己的进步

## 如何输出：3W（学习知识万能公式）

### Why

为什么

```
例子：数据库（为什么需要它呢？）
因为可以利用数据库可以达到储存数据的目的
```

### What

这是什么东西

```
例子：数据库（这是什么东西？）
可以用数据库的SQL语句来达到**增删改查**的目的
```

### How

这个东西怎么用

```
例子：数据库（这个东西怎么用呢？）
代码语句调用SQL语句
```
