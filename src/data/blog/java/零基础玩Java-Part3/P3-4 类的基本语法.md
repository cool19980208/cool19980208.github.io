# 类的基本语法
---

## 类的基础知识
- 1、private：只能类内部访问；public：其他类也可以访问
- 2、类的定义由成员变量和方法组成
  - 方法：动作
    - 大多数情况都是public
  - 成员变量：状态
    - 大多数情况都是private


## Java中定义一个类的语法


```java
public class Person 
{
    private  int age;//成员变量
    private String name;

    public void setAge(int value)
    {
        this.age = value;//给当前对象赋值
    }
    public void setName(String value)
    {
        this.name=value;
    }
    public  void sayHello()
    {
        System.out.println("大家好，我是"+this.name+",我今年"+this.age+"岁了。");//取值
    }
    public static void hi()
    {
        //static方法
        System.out.println("Hello wrold!");
        //this.age=5;  static方法中不能直接访问非static成员
    }
}

```



### 创建类的对象

```java
Person p1=new Person();
//Preson p1:声明Preson类型的的变量p1
//new Person():创建Person类的一个对象 或者说是 把Preson实例化
//Person p1=new Person(): 1.声明Preson类型的的变量p1 2.创建Person类的一个对象 3.把变量p1指向这个对象

```

### 方法调用

```java
p1.setAge(18);//调用p1变量“当前所指向对象”的setAge方法
```


## 类的另一种解读
- 类是把对象的若干个状态(成员变量)和相关的方法聚集到一个模板中的机制
- new一个类就是根据类的模板实例化出来一个对象
  - 不同的对象之间互不干扰

## static
- static方法和对象无关，因此可以直接通过类名调用
  - ![类名调用](https://github.com/cool19980208/picx-images-hosting/raw/master/20240809/类名调用.5j442hv6i4.webp)
  - 直接用类目. 去访问static方法
  - 用p1.hi()的话，是没有意义的，因为static方法与对象无关
  - static方法是不依赖于类的成员变量的
  - 好比:String也有static方法
  - ![类目调用1](https://github.com/cool19980208/picx-images-hosting/raw/master/20240809/类目调用1.3gobeg3jn1.webp)
- 非static方法需要通过对象调用
  - ![方法调用](https://github.com/cool19980208/picx-images-hosting/raw/master/20240809/方法调用.54xobmmvn0.webp)
  - 非static方法是依赖于成员变量的，所以不能直接使用类目去调用


```java
public static void hi()
{
    System.out.println("Hello wrold!");
    //this.age=5;  static方法中不能直接访问非static成员
}
```
