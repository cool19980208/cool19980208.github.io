## 需求说明
- 从网上找到各国疫情数据，保存到Excel、txt等，然后分析10个主要国家的疫情，分别形成条形图、饼状图。
  - 目前用到的页面: https://www.bitpush.news/covid19/  如果访问不了，就找别的数据源
  - 以后还可以学习爬虫技术自己抓取数据

txt文件内容
> 美国	59031556	835815
印度	35226386	483178
巴西	22328252	619654
英国	14279775	150222
法国	11618224	126195
俄罗斯	10437471	308258
土耳其	9852458	83388
德国	7458433	113717
意大利	7083762	138697
西班牙	6922466	89837
伊朗	6204224	131821

```java
String[] lines = IOHelpers.readAllLines("D:/JavaTest1/疫情/疫情.txt");
String[] countries=new String[lines.length];//用来存放国家的数组
Integer[] 确诊数量 = new Integer[lines.length];//用来存放确诊数量的数组
Integer[] 死亡数量 =new Integer[lines.length];//用来存放死亡数量的数组
for (int i =0;i< lines.length;i++)
{
    String line =lines[i];
    String[] datas = line.split("\\s");//\\s 是正则表达式,代表了空格和Tab, 只要是空,就算
    //System.out.println(Arrays.toString(datas));//先输出一下看看正确不
    String 国家 =datas[0];
    int 确诊 = Integer.parseInt(datas[1]);
    int 死亡 = Integer.parseInt(datas[2]);
    countries[i]=国家;
    确诊数量[i]=确诊;
    死亡数量[i]=死亡;
    //System.out.println(国家+确诊+死亡);
}
XSSFWorkbook workbook = ExcelHelpers.createXLSX();//创建xlsx
XSSFSheet sheet = workbook.createSheet();//创建页签
XSSFChart chart = ExcelHelpers.createChart(sheet, 1, 1, 20, 26);//在sheet上创建一个图表对象，显示到左上角坐标为(coll，row)、右下角坐标为(col2，row2)这个位置
chart.setTitleText("疫情统计");//图表标题
chart.getOrAddLegend().setPosition(LegendPosition.LEFT);
ChartFromArrayBuilder<Integer> chartBuilder = new ChartFromArrayBuilder<>(ChartTypes.BAR);//设置显示的图像:折线图  3D图等
chartBuilder.setCategoryNames(countries);
chartBuilder.putValues("确诊数量",确诊数量);
chartBuilder.putValues("死亡数量",死亡数量);
chartBuilder.build(chart);
ExcelHelpers.saveToFile(workbook,"D:/JavaTest1/疫情/疫情.xlsx");
ExcelHelpers.close(workbook);
DesktopHelpers.openFile("D:/JavaTest1/疫情/疫情.xlsx");//用默认方式去打开文件
```
