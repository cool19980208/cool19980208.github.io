# 常用数据类型

## 程序=命令+数据+逻辑

- 方法/函数
  - 查询可用日期,组装载人火箭
- 数据类型
  - 限制每个数据的范围
  - int
- 字面量
  - 比如下面的60，306
- 变量
  - 变量就是用来获取别人给你数据的一个途径而已
    - （好比：矿泉水瓶，里面装这水，水就是数据。当我喝了就是把数据给我了）
  - 变量就是数据的中转站，变量就是拿过来数据给别人使用的
  - 比如date,weight

## 常用数据类型
- 整数：主要是int。还有long、short、byte等。
  - 1、0、-1、365 
- 浮点数：主要是float。还有double
  - 0.03、3.14、-1.68
  - 单精度，双精度
- 字符：char
  - 'a'、'w'、'鑫'。一个汉字是一个字符，也只能是一个字符，空也不可以
- 字符串：String
  - "Hello"、"java"、"rzx18"
  - 字符串中\和换行的转义(难点):"hello\\world\n你好"
    - \\代表一个字符，显示出来就是\
    - \n是换行符
- 布尔值：boolean
  - true、false  真假值
