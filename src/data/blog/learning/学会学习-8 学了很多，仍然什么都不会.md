# 学了很多，仍然什么都不会

适应于所有方面（包括关于英语、编程、数学......）

## 目前教育的问题
- 学完的知识都不知道有什么用途？（学那么多，有什么用呢？）

### 书：《卓越密码：如何成为专家》
- 知识分类
  - 元知识（基础知识）
    - 比如数学的微积分、求导概念方程等
    - 计算机的基础语法等
  - 领域知识（专业知识）
    - 计算机的专业术语、工作流程、业务流程等
  - 客户知识

## 怎么把基础知识和专业知识去结合使用呢？
### 陷阱
- C语言必读的10本书
  - 还没开始学，就已经被怕跑了

### 英语的看法 
- 只会英语专业的人已经不值钱了，因为各个行业的人都在学习英语，虽然没有英专的人口音正，但只要不影响沟通即可
  - 建议：要尝试找到英语和某一个行业结合
    - 例子：做外贸行业的英语
### 不要“过度学习”，学完一个阶段就尝试应用起来，在实践中再去逐渐接触更高级的“基础知识”

- 步骤
  - 1.学习完一个阶段后总结一下
  - 2.想一想可以把学习到的知识应用到哪里去？去实际的解决他人或自己的问题
  - 3.在实践的过程中，自然而然会接触到更高级的“基础知识”
  - 4.这才是对于知识的**吸收**，而不是单纯的存放在脑子里不去调用练习的沉沙
```
  - 数学
    - 数学的微积分能用在哪里呢？建筑行业还是？
  - 编程语言
    - 不要迷失在框架中，能用简单的代码去解决复杂化的问题，比单单只会用框架厉害多了
  - 英语
 ```
