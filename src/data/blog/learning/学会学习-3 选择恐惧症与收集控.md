# 选择恐惧症与收集控

## 选择恐惧症 变成语言学Java还是C#
1.原因
- 害怕失去，害怕缺点
- 心理学：布里丹之驴

2.分析

- 万事万物都是优缺点共存的，需要trade off（折中）
- 解决方法：排除明显不靠谱的选项外，列出待选项的优缺点，然后打分。
- 如果还无法决定？toss a coin（抛硬币）
```
大多数失败不是由于决策错误，而是由于"优柔寡断，四面出击"
  - 杨中科老师的例子：上大学时，各种语言都学个遍，最后钻透Delphi语言，但没想到毕业时，Delphi已经没落，最后有编程语言的底子，直接转到了Java
```
3.总结
- **一旦选择决定了，就坚定执行下去**
- **路是走出来的，不是选出来的**
- **行动  > 选择**

## 收集控
1.原因
- 完美心态
- 害怕失去
  
2.分析

- 存到硬盘中的不是知识，存到脑子中的才是知识
- 存到脑子中的是知识，把知识实践起来才是**学习**，要知行合一
- 搜集资料设定目标（一套视频资料或一本书）
  - 书的学习效率要比视频教程高
  - 一本书就够了，只要不是烂到渣，学下去没有错
  - 及时刹车
  - 不要**过度学习**

## 作业
- 记笔记（结合直接的情况），写到评论区
- 完成第二课《大战拖延症》的作业
- 清理收藏夹，清理硬盘。把剩下的开始学习，记笔记。
  - 收藏夹，硬盘。只留最重要的，然后开始学习
