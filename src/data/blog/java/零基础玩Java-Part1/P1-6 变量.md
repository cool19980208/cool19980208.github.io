## 变量命名的规范
- 1、要取有意义的变量名，不要a1、a2、x1
  - 这是程序员默认的潜规则
  - 这样去写代码，显的不是很专业
- 2、变量一般小写开头，遵守驼峰法
  - 除了第一个单词小写，后面的单词首字母大写
    - 比如helloWrold
- 3、如果英语很不好或者专业术语不知道怎么翻译或者非专业程序员，可以根据情况决定是否用中文变量名
- 关于**代码坏味道**
  - 如果平时写代码都是a1、a2的变量的例子和代码风格写的不好的人，显的很不专业，如果进入公司的后续也很难在规范
