# 共享文件夹的连接

## 1.第一步打开命令行
- Win+R 输入 
  ```
  \\WIN-0EB6Q7A0LB8
  ```
  - ![Win](https://github.com/cool19980208/picx-images-hosting/raw/master/20240729/Win.6t70syfkqb.webp)
- 点击确定
  
  - ![CMD输入](https://github.com/cool19980208/picx-images-hosting/raw/master/20240729/CMD输入.4qr84wfiet.webp)

## 2.选择共享的文件夹
- 右键共享的文件夹
- 选择 映射网络驱动器
  - ![映射网络驱动器](https://github.com/cool19980208/picx-images-hosting/raw/master/20240729/映射网络驱动器.3uuqpg5tyu.webp)
- 点击确定即可
  - ![完成1](https://github.com/cool19980208/picx-images-hosting/raw/master/20240729/完成1.9rjawgmcxi.webp)
