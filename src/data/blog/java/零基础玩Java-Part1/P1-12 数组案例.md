## 计算2个等长数组元素逐位的和

![计算2个登场数组元素逐位](https://github.com/cool19980208/picx-images-hosting/raw/master/20240801/计算2个登场数组元素逐位.99t9cgf4wk.webp)

```java
//计算2个等长数组元素逐位的和
int[] nums1={6,8,11};
int[] nums2={8,6,12};
int[] nums3=new int[nums1.length];
for (int i =0;i<=nums1.length-1;i++)
{
    nums3[i]=nums1[i] + nums2[i];
}
System.out.println(Arrays.toString(nums3));
```


## 查找数组中最大值
- 思路很重要

![查找数组中最大值](https://github.com/cool19980208/picx-images-hosting/raw/master/20240801/查找数组中最大值.4g4egbufte.webp)


```java
//查找数组中最大值
int[] nums={3,5,8,93,777,666,888,999,1888,8888,9999,1314};
int max=nums[0];
for (int i=1;i<nums.length;i++)
{
    int n=nums[i];//找一个变量来存放循环取出来的值
    if (n>max)
    {
        max=n;//当取出来的值大于前一个最大值时，则更新最大值
    }
}
System.out.println(max);
```
